# crypto-museum-game
interactive game

## ⚠️ Правила работы с репозиторием

- НЕ пушим напрямую в `main`
- Вся работа ведётся в ветке `dev`
- В `main` код попадает только через Pull Request (dev → main)

# Как запустить проект «Ключ к доверию»
## Шаг 1. Установить (если ещё не стоит)

1. **Git** — https://git-scm.com/downloads
2. **Docker Desktop** — https://www.docker.com/products/docker-desktop/ (после установки — запусти его и дождись, пока значок кита в трее перестанет мигать)
3. **Node.js** (версия LTS) — https://nodejs.org/

Проверить, что всё встало, можно так: открыть терминал (PowerShell на Windows, Terminal на Mac) и по очереди ввести:

```
git --version
docker --version
node --version
```

Если каждая команда показала версию, а не ошибку — всё готово.

---

## Шаг 2. Скачать проект

```
git clone https://github.com/Cryptography-Museum-Project/crypto-museum-game.git
```

Если проект уже скачан раньше и нужно просто обновить до последней версии — зайди в папку проекта и выполни:

```
git pull
```

---

## Шаг 3. Запустить backend (серверную часть)

Открой терминал, перейди в папку `backend` внутри проекта:

```
cd crypto-museum-game/backend
docker compose up --build
```

Подожди, пока в терминале не появится строка `Uvicorn running on http://0.0.0.0:8000`. Это окно терминала **не закрывай** — сервер работает, пока оно открыто.

Проверить, что сервер живой: открой в браузере http://localhost:8000/docs — должна открыться страница со списком API.

---

## Шаг 4. Запустить frontend (саму игру и админку)

Открой **второе, новое** окно терминала (первое не трогай), перейди в папку `frontend`:

```
cd crypto-museum-game/frontend
npm install
npm run dev
```

Терминал покажет ссылку вида `http://localhost:5173` — это и есть адрес запущенного проекта.

---

## Шаг 5. Что открывать в браузере

| Что | Адрес | Вход |
|---|---|---|
| Сама игра | http://localhost:5173 | не требуется |
| Админ-панель | http://localhost:5173/admin | логин `admin`, пароль `admin123` |

Оба адреса работают только пока открыты **оба** окна терминала (backend и frontend).

---

## Как всё остановить

В каждом из двух окон терминала нажать `Ctrl + C`.

Чтобы запустить снова в другой раз — повторить шаги 3 и 4 (`git pull` из шага 2 стоит делать каждый раз перед запуском, чтобы тестировать самую свежую версию).

---

## Если что-то не работает

- **Игра показывает "не удалось связаться с сервером"** — значит, не запущен или упал backend (шаг 3). Проверь то окно терминала, не закрылось ли оно, и что там нет красных ошибок.
- **`docker compose up` ругается ошибкой про WSL** — попробуй полностью закрыть и заново открыть Docker Desktop, подождать, пока он полностью загрузится, и повторить команду.
- **`npm run dev` ругается на отсутствующие пакеты** — выполни `npm install` ещё раз внутри папки `frontend`.
- Если ошибка непонятна — сделай скриншот всего текста ошибки и пришли в чат команде, разберёмся вместе.
